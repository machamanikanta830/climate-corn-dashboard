#  Impact of Climate Trends on Corn Yields Across U.S. States (2000–2024)

##  Interactive Data Visualization – Course Project

###  Overview
This project explores how long-term climate factors—particularly **average annual temperature (TAVG)** and **precipitation (PRCP)**—affect **U.S. corn yields** over time.  
Using data from the **NOAA Climate Data Online (CDO)** API and the **USDA NASS Quick Stats** database, we integrate and visualize state-level trends to understand how climate variability influences agricultural productivity.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/machamanikanta830/climate-corn-dashboard.git
cd climate-corn-dashboard
```

### Install Dependencies

```bash
npm install
npm install d3 topojson-client
```
### Run the Application

```bash
npm run dev
```

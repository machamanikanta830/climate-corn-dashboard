# Portfolio and résumé notes

## Short project description

Climate + Corn Explorer is a Vue and D3 dashboard that combines 25 years of
NOAA climate observations with USDA state corn-yield estimates. Its coordinated
views support geographic comparison, year filtering, scatterplot brushing, and
state-level drill-down while clearly separating descriptive correlation from
causal claims.

## Draft résumé bullets

Use **co-developed** unless your personal contribution supports a stronger and
more specific verb.

- Co-developed an interactive Vue 3 and D3 dashboard coordinating maps, trend
  charts, scatterplot brushing, rankings, and state drill-downs across 1,025
  state-year observations from 2000-2024.
- Built a reproducible Python workflow to collect NOAA climate observations,
  clean USDA NASS corn-yield records, merge state-year data, and validate 41
  states with complete 25-year coverage.
- Translated pooled correlation results into an explorable visual narrative,
  documenting methodological limitations and distinguishing association from
  causation.

## Interview talking points

- Why Vue owns application state while D3 owns scales, geometry, and SVG marks.
- How state selection, year filtering, brushing, and linked hover states are
  coordinated across components.
- Why a pooled correlation can differ from national yearly averages or
  within-state relationships.
- Why station means are not equivalent to area-weighted or corn-acreage-
  weighted climate measurements.
- How automated validation prevents the README, landing page, and dataset from
  drifting apart.
